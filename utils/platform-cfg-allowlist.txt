# Files still allowed to select code at compile time outside libprof.
#
# Roofline's calibration kernels are AVX-512/AVX2/RVV microkernels and its QEMU
# driver is process plumbing; neither measures the host through libprof, so
# both keep their compile-time dispatch until roofline grows its own platform
# module. The kernels cannot move into utils/roofline-core, which is linked as
# a static library into the DynamoRIO client and the QEMU plugin: that would
# put rayon and mperf-data inside every instrumented process.
#
# store/clock.rs is the CLOCK_MONOTONIC binding a recording is anchored to. It
# has to be the same clock perf timestamps come from, and store cannot depend
# on libprof (Windows builds the viewer without it), so the syscall is selected
# here. It is one function alone in its own file so the rest of store stays
# guarded.
#
# Every other entry is a bug: branch at runtime instead.
mperf/src/roofline/calibrate.rs
mperf/src/roofline/qemu.rs
